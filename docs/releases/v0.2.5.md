# FlexSDS v0.2.5 — Multi-GPU Benchmark, Batch-K Controller & Measured GPU Profiles

FlexSDS v0.2.5 adds the multi-GPU benchmark command. It ships measured cost profiles for every Modal GPU and makes the adaptive controller decide per batch. It also fixes the CLI defects found in end-to-end tests on Windows and Modal.

**Version number.** PyPI release 0.3.4 was tag v0.2.4 published under a mistyped number. It is yanked, and this release continues the tag series as 0.2.5.

## New features

- **Multi-GPU benchmark:** `flexsds benchmark plan|run|status|validate|aggregate|stop` measures the three lanes (vanilla, static EAGLE K=3, adaptive) on the frozen workloads W1_V3, W2 and W3 at concurrency 1–32. Details:
  - Each GPU runs as one Modal container, and all lanes of a comparison run on the same card.
  - The campaign plan is frozen at a commit; failed cells can be re-measured with `--retry-failed`.
  - `stop --campaign-id` cancels only that campaign.
- **Measured GPU profiles in the package:** A10, T4 (batch 1–8), L40S and A100-80GB. Adaptive serving works on every Modal GPU without calibrating first. A measured profile is only used on the card it was recorded on.
- **Adaptive controller:**
  - acceptance is estimated per draft position (geometric MLE);
  - the draft budget K is chosen for the whole batch, and K = 0 turns speculation off under high load;
  - probing happens at batch level.
- **Benchmark evidence** keeps the hardware profile each GPU session used.

## Fixes and improvements

- T4 adaptive serving above batch 8 uses the batch-8 costs instead of crashing.
- `flexsds profile --benchmark --gpu-memory-utilization` sets the memory share used during calibration.
- Preflight uses the Hugging Face token saved with `flexsds auth login`, the `HF_TOKEN` variables, or the `huggingface-cli` token file for gated models.
- Each lane is served under its own model name (`<target>-adaptive|static|vanilla`).
- The Modal endpoint URL is read correctly when the output is piped.
- `flexsds monitor` shows the scheduling step and skipped feedback, and reads aggregate request records.
- `flexsds auth login` without a terminal reads the secret from stdin, or exits with an error instead of hanging.
- Benchmark client keep-alive is shorter than the vLLM server's, so idle connections are no longer reset mid-run.

## Usage notes

- `flexsds serve --gpu T4` with the defaults (context 4096, 32 sequences) is blocked by preflight: the estimated VRAM (15.8 GiB) exceeds the T4 budget (14.6 GiB). Lower `--max-model-len` or `--max-num-seqs`, or accept the risk with `--allow-oom-risk`.
- `flexsds benchmark run` must be started from a committed source checkout (the plan records the commit). An installed wheel can plan and preview (`--dry-run`) only.
- Modal deployments need `modal` 1.6.4 or newer.

## Upgrade

After this version is published to PyPI:

```bash
python -m pip install --upgrade "flexsds==0.2.5"
flexsds --version
```

From the repository:

```bash
git checkout v0.2.5
python -m pip install -e .
```

On Windows, use `py -m pip` if that is the interpreter where FlexSDS is installed.
