# FlexSDS v0.3.4 — Modal Endpoint Management & Hardware Profile Import

FlexSDS v0.3.4 adds deployed endpoint management, hardware profile import, and
clearer feedback during setup and GPU startup.

## New features

- **Running endpoint:** browse deployed Modal web endpoints, including idle
  deployments; inspect URLs, GPUs, App IDs, and deployment metadata; chat with
  an endpoint or stop its deployment after confirmation.
- **Hardware profile import:** paste JSON in a terminal dialog, submit with
  Ctrl+X, or import from a local file or direct HTTP(S) JSON URL. Imported
  profiles are stored as JSON artifacts and indexed in SQLite, with duplicate
  detection by content hash.
- **Profile management:** choose between `Measure now` and `Import hardware
  profile` while keeping the existing Fast/Full measurement modes.
- **Modal onboarding:** automatically install missing Modal tooling, show
  English token setup instructions, verify credentials, and display the
  associated workspace before saving. Delete local tokens from the main menu.

## Fixes and improvements

- Fix Windows path escaping in Modal image configuration using base64 transport.
- Follow production runtime logs after deployment so model loading and GPU
  warmup remain visible in the Ctrl+O viewer.
- Wait for publication to finish before checking endpoint readiness; display
  health, model discovery, inference, and retry status.
- Fix Windows arrow-key handling and keep the log viewport stationary when
  scrolling through history while new logs arrive. Support j/k and G shortcuts.
- Show a spinner during model compatibility checks.
- Return to the main menu after hardware detection, token deletion, and profile
  import.
- Finalize adaptive and profile settings before updating the Colab notebook;
  stop setup when the configured notebook cannot be written.

## Usage notes

- Profile imports retain measurement validation. Legacy profiles can be stored,
  but importing them does not make them eligible for adaptive serving.
- Stopping a deployment stops all endpoints belonging to that Modal app.
- Upload the locally configured notebook to Colab again after changing wizard
  settings; the repository notebook URL opens the template.

## Upgrade

After this version is published to PyPI:

```bash
python -m pip install --upgrade "flexsds==0.3.4"
flexsds --version
```

On Windows, use `py -m pip` if that is the interpreter where FlexSDS is installed.
