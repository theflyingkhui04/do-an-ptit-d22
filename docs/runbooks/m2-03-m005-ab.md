## Bounded observations and added-hook justification

- Existing scheduler observation location supplies the selected controller and
  current/future plan. A separate producer pointer/row binds consumed drafts to
  their producer, because request-wide telemetry cannot establish this lineage.
- V1 pre-forward hook binds actual M/positions/input IDs to the selected attempt.
  No prefill tensor capture; GPU reads are gated to a small output-count window.
- The layer0 backend's pre/post hooks supply original-bit Q, logical K/V hashes,
  layout/metadata and selected-row output. Other layers perform no tensor reads.
- Unified attention observes the actual grid/tile and branch immediately before
  launch. It never recomputes attention or substitutes output.
- Raw logits and existing-equivalent sampler/rejection-score anchors are needed
  to bind the selected processed vector to token341/token5212. No existing summary
  telemetry exposes these selected-row scores.
- Scheduler before/after output-update anchors distinguish sampling from actual
  commit. A rejected/stale attempt cannot resolve index162. Captures keep all
  boundary-covering attempts and require one unique committing attempt.

Metadata-only lineage is retained for the selected request; tensors are read only
for layer0 in forwards actually containing position1683. The observer never calls
select/update controller methods, writes engine tensors, allocates CUDA scratch,
or performs an additional forward/kernel computation. CPU readback changes timing;

## Classification and limits

The analyzer validates exclusive seals, frozen payloads, raw HTTP records, source
backups/composed hashes, observer identity, sequence completeness and committing
row linkage. A checksum-only seal cannot make missing or semantically invalid
events acceptable. Sources are sealed before restoration and historical evidence
is never overwritten.

Require the same T4/session/software/revisions, conditioning outputs, token prefix,
controller state, producer/consumer budgets, M, input positions/IDs, consumed drafts,
graph regime, layer0 Q and logical K/V. Physical block addresses may differ;
logical content must match. Dispatch and launch geometry are the treatment.
Only the telemetry artifact destination may differ in the shared runtime config.

- `INVALID_EVIDENCE`: missing/malformed events, source/hash drift, unsupported
  runner/mode, observer error or ambiguous commit ownership.
- `INCONCLUSIVE`: valid evidence but A does not reproduce5212, any comparability
  gate fails, or the boundary does not isolate an active rowwise/native contrast.
- `ROWWISE_POLICY_CAUSAL`: comparable A=5212 and B=341.
- `ROWWISE_POLICY_NOT_SUFFICIENT`: comparable A=B=5212; removing the policy alone
  did not restore the reference in this diagnostic.

Equal pre-state and unequal layer0 attention output localize a layer0 attention
difference. Unequal pre-state is inherited divergence with operator origin unknown.
Equal layer0 output with different logits places the observed difference outside
that output. Token restoration is never a kernel-level root cause. All results
retain `task_done=false`; no M2-03 acceptance threshold is introduced.
